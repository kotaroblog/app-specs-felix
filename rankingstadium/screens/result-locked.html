結果ロック画面

期間終了後・未投票・閲覧不可ユーザー向けの遮断画面

v1.3 画面ID: RS-VOTE-05

目的・役割

投票期間が終了し、自分が投票していないかつ閲覧権限がないランキングについて、結果閲覧をブロックする画面。 ポイント消費で閲覧解放できる導線を提供。

UI 構成

要素種類説明
ロックアイコンSF Symbol「lock.fill」
説明テキストText「投票期間が終了しました。閲覧にはポイントが必要です」
閲覧解放ボタン（ポイント）Button「Npt消費して結果を見る」（PointAction.viewResult）
閲覧解放ボタン（報酬）Button「無料で結果を見る」。報酬（+3pt）を受け取って unlocked_rankings に INSERT する。1日5回まで（adUnlockRemainingCount）。広告配信が有効な環境ではリワード広告の視聴完了後に、無効な環境では広告なしで即座に付与する（広告制御）
内訳トーストToast（上部）アンロック直後に約2.2秒間フェード表示。報酬が実際に付与された場合のみ表示。日次上限到達時・ポイント直接消費時は非表示
戻るボタンToolbarRankingDetailView または前画面へ

状態

状態表示内容
初期表示ロック画面 + 解放ボタン
解放処理中ProgressView
ポイント不足「ポイントが足りません」
解放成功（報酬）ResultView へ遷移 + 内訳トーストを約2.2秒間表示
解放成功（ポイント直接消費）ResultView へ遷移（トーストなし）
報酬の日次上限到達（5回）「今日の上限に達しました」エラー表示（トーストなし）

遷移

操作遷移先
「閲覧する」PointService.consumePoints(viewResult) → ResultView
戻るRankingDetailView

使用するデータモデル

PointAction.viewResult       // 1pt
PointAction.viewDetail       // 2pt
PointAction.viewConditional  // 3pt

実装メモ

  • RankingAccessPolicy で閲覧不可と判定された場合のみ表示
  • 解放後の状態は accessPolicy に反映され、再表示時にスキップ
  • 報酬アンロックは RewardedAdManager.shared.show(onReward:) のコールバック内で performUnlock(userId:rankingId:) を呼ぶ。広告配信が無効な環境では show() が広告を出さずに成功として返り、報酬が即座に付与される
  • 報酬アンロックの 1 日上限管理（adUnlockRemainingCount = 5回）。広告の有無にかかわらず上限は維持
  • アンロック直後に内訳トーストを上部フェード表示（約2.2秒）。+3pt 付与 → −1pt 消費の2段階増減を可視化。ワンタップの操作フローは変更なし
  • トースト表示条件: 報酬が実際に付与された場合のみ。日次上限到達時・ポイント直接消費時は非表示
  • ボタン文言は広告に言及しない表現（「無料で結果を見る」）に統一。広告を再開する際に戻せるようコードにコメントを残している
