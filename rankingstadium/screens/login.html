ログイン画面

アプリの説明と認証エントリポイントを兼ねる、初回起動で必ず通る唯一の画面

v1.1 画面ID: RS-AUTH-01

目的・役割

未認証ユーザーの入口。Apple Sign In とゲスト利用の2つの導線を提供する。 この画面はアプリ内で唯一の「初回説明」の場でもあり、 ロゴとキャッチコピーだけでは何をするアプリか伝わらないため、サインインを求める前に3ステップの説明を置く。

UI 構成

要素種類説明
アプリロゴImageトロフィーアイコン（ピンク→オレンジのグラデーション）＋アプリ名「ランスタ」
キャッチコピーText「みんなで作るランキング」
3ステップ説明ViewThatFits「1 投票する → 2 結果を見る → 3 自分で作る」。v1.1 で追加。詳細は下記
Apple Sign In ボタンButton黒背景・角丸16・最小高さ54。処理中は ProgressView に差し替え
EULA 同意文＋規約リンクText / Link「サインインすることで、以下に同意したものとみなされます」＋利用規約・プライバシーポリシー（App Store ガイドライン 1.2 UGC 対応）
ゲスト導線Button「登録せずにゲストで始める」。登録なしで投票を試せる（作成・フォロー等は登録後）

3ステップ説明（v1.1 で追加）

従来はトロフィーアイコンと「みんなで作るランキング」だけで、 何をするアプリか分からないまま Apple Sign In を要求していたため、 初回の離脱要因になっていた。番号バッジ＋ラベルの3ステップを、ロゴとサインインボタンの間に置く。

ステップラベル対応する体験
1投票する既存ランキングへの投票（ゲストでも可）
2結果を見る投票すると結果が解放される（ポイント経済の入口）
3自分で作るランキングの作成（要登録・ポイント消費）
  • 横並びが入りきらない場合は縦積みにフォールバックする（ViewThatFits(in: .horizontal)）。 Dynamic Type を拡大しても文字が切れない
  • 番号バッジの直径は @ScaledMetric(relativeTo: .footnote) で文字サイズに追従する （固定値だと拡大時に数字が円からはみ出すため）
  • ステップ間の矢印は装飾のため accessibilityHidden。各ステップは 「ステップ1、投票する」の形で1要素として読み上げる

使用するデータモデル

// ASAuthorizationAppleIDCredential
// → AppleSignInService → Supabase auth.signInWithIdToken()
// → AuthViewModel.fetchOrCreateUser()

実装メモ

  • SecRandomCopyBytes で nonce 生成、SHA256 ハッシュ化
  • CheckedContinuation で非同期結果を await キャッチ
  • Supabase セッション復元（キーチェーン経由）
  • Apple Sign In キャンセルはサイレント扱い
