豆知識クイズ画面

豆知識に付随する選択式クイズ

v1.0 画面ID: DT-QUIZ-01

目的・役割

豆知識（tip.quiz）に付随する3択問題を解く画面。正解で連続日数（streak）+1、コインも獲得可能。

UI 構成

要素種類説明
問題文Texttip.quiz.question
選択肢ボタンButton×3tip.quiz.choices。ヒントで消した選択肢は押せない行（QuizEliminatedChoiceRow）で表示
ヒントボタン（1.0.14）QuizHintButton問題の下。「ヒント（10pt）間違いを1つ消す」。残高不足は押せず「ヒントまで あと◯pt」、使用後は「ヒントで間違いを1つ消しました」。未回答かつ再挑戦・過去の日でないときだけ出す → ヒント
結果表示Overlay正解 / 不正解の演出
正答率表示Text「N% 正解」
連続正解日数Text「連続N日」
獲得コインText「+1 コイン」（正解時）
「もっと解く」ボタン（1.0.13）DailyQuizNextStepView結果の下、閉じるボタンの上。「「◯◯」のクイズをもっと解く」と、入り方に応じた補足（解放済み「100問・解説つき」／お試し未使用「まずは無料でお試し5問」／お試し済み「100ptで100問を解放できます」）

状態

状態表示内容
未回答選択肢＋ヒントボタン（今日の問題のみ）
ヒント使用後（1.0.14）間違いの選択肢1つを押せない行で表示・使用済みのチップ
再挑戦・過去の日再挑戦のバッジ。ポイントが入らないのでヒントは出さない
正解正解演出 + 統計表示
不正解正解を提示 + 解説
当日回答済み「本日は回答済み」表示

遷移

操作遷移先
選択肢タップ結果表示（同画面）
「もっと解く」（解放済み・無料ジャンル）GenreQuizPlayView（回答があれば続きから・なければ1問目から）(.sheet)
「もっと解く」（未解放・お試し未使用）GenreQuizPlayView（お試し5問）(.sheet)
「もっと解く」（未解放・お試し済み）GenreQuizShopView（一覧で解放を案内）(.sheet)
閉じるHomeView（sheetを閉じる）

使用するデータモデル

TipQuiz {
    let question: String
    let choices: [String]
    let correct: Int  // index
}

QuizService {
    func recordAnswer(tipId: String, correct: Bool)
    func getStreak() -> Int
    func hasAnsweredToday() -> Bool
}

実装メモ

  • QuizService.hasAnsweredToday() で1日1回制限
  • 正解時 streak +1 + コイン獲得（CoinService 連携）
  • 不正解時 streak リセット
  • 1.0.13: 「もっと解く」の対象は豆知識のカテゴリと同じジャンル（科学・雑学・歴史）。「文化」は 1.0.13 では無料の「雑学・トリビア」へつないでいたが、1.0.14 から新ジャンル「日本の文化・行事」へつなぐ
  • 1.0.14: ヒントの使用済みの記録はアプリを閉じても残り、同じ問題で二重に 10pt を引かない。回答したら記録を消す
  • 1.0.14: 配色ひだまり（正解 #D8F0DC／#176B3C、不正解 #FADCDC／#B3261E）
  • 1.0.13: 入り方の判定（解放済みか・進捗があるか・お試し済みか）は純粋な関数にして単体テストで確認
