ジャンルクイズショップ

14ジャンルから興味のあるものをコイン購入で解放（雑学・トリビアは無料）

v1.1 画面ID: DT-GQS-01

目的・役割

14のジャンルから興味のあるものを解放し、ジャンル別クイズで集中学習する画面。 「雑学・トリビア」は完全無料（cost: 0）、その他13ジャンルは最初の5問が無料お試し、全問解放は 100コイン。

状態

状態表示内容
完全無料ジャンル（雑学・トリビア）「無料」バッジ + 「プレイ」ボタン
未アンロック（5問お試し未使用）ピンク「お試し5問」バッジ + 「お試し5問」ボタン + 「100ptで解放」ボタン
未アンロック（5問お試し使用済み）v1.0.7グレー「お試し済み」バッジ + 無効化「お試し済み」ラベル + 「100ptで解放」ボタンのみ操作可
残高不足（1.0.13）解放ボタンは押せるまま「🪙 100ptで解放」の下に「あとXpt」。押すとアラート「あとXptで解放できます」＋貯め方（動画を見て +3pt〔1日5回まで〕・毎日のログイン +1pt・今日のクイズの正解 +1〜3pt）
アンロック済「プレイ」ボタン → モード選択

GenreDefinition {
    let id: String

GenreQuizService {

    func isUnlocked(id: String) -> Bool

実装メモ

  • 14ジャンルの定義は GenreDefinition の static 定数
  • 雑学・トリビアは cost: 0 で常時アンロック扱い
  • お試し5問は解放前にプレビュープレイ（回答記録はしない）。v1.0.7 から1ジャンル1回限り（5問完走時に markFreeTrialUsed(for:) でフラグ記録）
  • v1.0.7: @State playSession: GenrePlaySession? で genre+mode をアトミックに渡し、シート presentation 時の race condition を排除
  • unlockGenre() で CoinService.spendCoins(100) → 成功で AppGroup に保存
  • プレイ開始時に Interstitial広告を挟む（無料ユーザー）
  • 動画ボーナスボタンから RewardedAdManager.show() を起動
  • 実績サマリーの「詳細 ›」は GenreProgressView へ遷移
  • 1.0.13: 入口はホーム上部の「クイズ」、ホームのポイントの使い道、今日のクイズの後（お試し済みのとき）、お試し終了画面の「ほかのジャンルを見る」。開いた入口を genre_shop_viewed（source）で記録
