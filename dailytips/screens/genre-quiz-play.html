ジャンルクイズプレイ画面

ジャンル別の問題を解くプレイ画面（3モード対応）

v1.1 画面ID: DT-GQS-02

目的・役割

解放済みジャンルの問題を4つのプレイモード（ランダム / 順番通り / 続きから / お試し）で解いていく画面。

プレイモード

モード動作進捗記録
ランダム未回答問題からランダムに出題あり
順番通りposition をリセットして1問目からあり
続きから保存された position から再開あり
お試し（v1.1）未解放ジャンルで最初の5問のみ出題なし（解放後に改めて記録）

お試しモード終了画面（v1.1）

お試し5問終了時、「お試し終了！」ヘッダーと「◯ / 5 問正解」を表示する。1.0.13（未公開）から、その場で解放して続けられる（DT-016。一番気持ちが高まったところで止めないため）。

状況表示押したとき
残高が足りる「🪙 100ptで解放する（残高 Ypt）」解放し、お試しの5問の回答を進捗に記録して 6問目から続ける（同じ画面）
残高が足りない「解放まであとXpt（残高 Ypt / 100pt）」＋「動画を見て +3pt」＋「毎日のログイン（+1pt）と今日のクイズの正解（+1〜3pt）でも貯まります」動画ボーナスでその場で貯められる。足りた時点で解放ボタンに切り替わる
「ほかのジャンルを見る」の先でこのジャンルを解放して戻った「続きから遊ぶ（6問目から）」ptは使わずに6問目から続ける
  • 下段に「ほかのジャンルを見る」（今日のクイズの後から開いたときは一覧を開く）と「閉じる」
  • 解放して続けたとき、終了カードの「このセッション」の数にお試しの5問は含めない

状態

状態表示内容
未回答問題文 + 選択肢
回答後正解強調 + 解説
全問終了「全問終了！」＋このセッションの正解数＋閉じる

お試し終了上記「お試しモード終了画面」

遷移

操作遷移先
選択肢タップ同画面（結果表示）
「次へ」同画面（次問題）
終了開いた元へ戻る（一覧／今日のクイズ）
「最初から解き直す」同画面（順番通りで1問目から）
お試し終了画面の「ptで解放する」／「続きから遊ぶ」同画面（6問目から）
お試し終了画面の「ほかのジャンルを見る」GenreQuizShopView

使用するデータモデル

GenreQuizQuestion {
    let id: String
    let question: String
    let choices: [String]
    let correct: Int
    let explanation: String?
}

GenreProgressService {
    func recordAnswer(genreId: String, questionId: String, correct: Bool)
    func getPosition(genreId: String) -> Int
}

実装メモ

  • プレイ開始時にInterstitial広告（無料ユーザー）
  • 回答ごとに GenreProgressService.recordAnswer() で進捗保存
  • 「続きから」モードは position を維持
  • 1.0.13: 今日のクイズの後からも開く（isLaunchedFromShop: false）。その場合「ほかのジャンルを見る」で一覧を開く
  • 1.0.13: お試し中の回答は記録せずに保持し、終了画面で解放したときだけまとめて記録する
  • 1.0.13: 問題番号の計算は純粋な関数（GenreQuestionNumbering）にして単体テストで確認
