鳥の着せ替え画面

ポイントで小物を買い、鳥に着せる・外す（シート）

v1.0 画面ID: DT-CST-01 アプリ 1.0.14 (27)・未公開

目的・役割

テーマショップに代わるポイントの使い道。いまの鳥の姿を大きく見せ、頭・首・顔の小物11点を買う・着る・外すをこの画面で行う。 ルールは 鳥の着せ替え（機能）。

UI 構成

要素種類説明
ナビゲーションタイトルNavigationStack「鳥の着せ替え」。右上に閉じるボタン（PaletteToolbarCloseButton）
残高Text（チップ）「🪙 Ypt」。読み上げ「残高Yポイント」
鳥のカードCostumedBirdViewいま着ている姿。購入の確認中はその小物を着た姿（試着）を出す。下に着ている物の一覧と「ptで小物を買って着せられます。ホームとウィジェットの鳥も同じ姿になります。」
場所ごとの一覧セクション×3「頭」「首」「顔」の順。各行は CostumeItemRow
小物の行CostumeItemRow小物の画像・名前・状態（「着用中」／「持っています」／「◯ptで買えます」／「あと◯pt」）と、右のボタン（未所持「🪙 ◯pt」・所持「着る」・着用中「外す」）。ボタンは押せる範囲 44pt 以上
購入の確認Alert「◯◯を買いますか？」「◯ptを使います（残高 Ypt）。買ったらすぐ着せます。いつでも外せます。」／「買う（🪙 ◯pt）」「キャンセル」
残高不足Alert「あと◯ptで買えます」「画面上の「動画を見て +3pt」（1日5回まで）、毎日のログイン（+1pt）、今日のクイズの正解（+1〜3pt）で貯められます。」

状態

状態表示内容
何も着ていない鳥だけ
購入の確認中鳥のカードが試着の姿。キャンセルで元に戻る
買った直後自動で着た状態（行は「着用中」・ボタンは「外す」）。アニメーション 0.25 秒
同じ場所の別の物を着た前の物は「持っています」に戻る
すべて所持ホームのポイント欄に「小物はすべて集めました・いつでも着替えられます」

遷移

操作遷移先
ホームの入口「着せ替え」／鳥のカード／ポイント欄の「鳥の着せ替え（50ptから）」この画面 (.sheet)
閉じるホーム（ホーム・ウィジェットの鳥は新しい姿）

使用するデータモデル

CostumeItem { id, slot: CostumeSlot, name, price }   // 11点・Models/Costume.swift
CostumeOutfit { items: [CostumeSlot: CostumeItem] }  // 場所ごとに1つ
UserDefaults（App Group）
  costume_owned_ids : [String]
  costume_equipped  : [String: String]  // "head"|"neck"|"face" → 小物の id
