Premium 購入画面

サブスクリプションプランの購入

v1.0 画面ID: DT-PRM-01
アプリ 1.0.14 (27)（2026-10-23・未公開）: 配色「ひだまり」で塗り直した（共通の背景・白いカード・主ボタン #F09558 に濃い文字）。プランの選択部分を PremiumPlanSection.swift に切り出し。特典の内容（広告なし・全日付の閲覧・毎月100pt）は 1.0.13 のまま。テーマ廃止でプレミアムの特典に変更は無い。

目的・役割

プレミアム会員の特典を訴求し、月額・年額プランから選択して購入してもらう画面。

UI 構成

要素種類説明
ヘッダーVStack「プレミアムにアップグレード」＋「広告なし・全日付の閲覧・毎月100pt」

プレミアム特典

  • 広告なし（Banner / Interstitial すべて非表示。Rewarded は報酬目的で任意利用可）
    ※ アプリ起動広告（AppOpen）は 2026-08-20 に廃止済み。1.0.13 から特典一覧に「広告なし」を再び記載（実際に消えるバナーと全画面広告として）
  • 過去の豆知識をすべて閲覧（カレンダーの全日付）
  • 限定テーマすべて解放（実装検討） → 実装していないため 1.0.13 で画面・設定の記載を削除
  • 毎月1日に +100コインボーナス
  • 全ジャンル自動アンロック（実装検討）

使用するデータモデル

PremiumService {
    func fetchProducts() async
    func purchase(_ product: Product) async throws
    func refreshPremiumStatus() async
}

実装メモ

  • PremiumService は @Observable @MainActor
  • PurchaseError enum で productNotFound / verificationFailed / pending を定義
  • restorePurchases() の動線あり
  • 1.0.13: 価格は StoreKit の displayPrice を表示（以前の固定表記はやめた）。年額の割引率は、月額12か月分と年額の価格から計算して切り捨て（年額が安くなければバッジを出さない）。以前の固定表記「45%」は実価格では44%
  • 1.0.13: 割引率の計算は単体テストで確認（桁の多い値でバッジが消える不具合をテストで検出して修正）
  • 1.0.13: 価格の取得失敗は Logger に残す
  • 1.0.13: プラン選択と注意書きを PremiumPlanSection.swift へ分割
