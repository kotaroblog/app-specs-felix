ASOキーワード戦略

App Store Optimization の方針とキーワード設計（初版・要レビュー）

本ページは初版です。リリース後のレビュー流入・検索流入のデータを見て更新してください。

ターゲットユーザー

  • ペルソナ20〜50代、知的好奇心が高い層、毎日のスキマ時間を有効活用したい
  • 課題無駄な時間をなくしたい、雑学・教養を効率よく増やしたい
  • 利用シーン朝の通勤、寝る前の数分、仕事の合間の気分転換

App Store Connect 設定

  • アプリ表示名デイリー豆知識
  • アプリ名（30字）[要検討] 例: デイリー豆知識 - 毎日の雑学&クイズ
  • サブタイトル（30字）[要検討] 例: 1日1つ、新しい知識を発見
  • プロモテキスト（170字）（1.0.14・未公開）新ジャンル「日本の文化・行事」「乗り物・交通」「数学・論理」を追加し、17ジャンル1,700問に。アプリの鳥の着せ替えも登場。毎日1分、日めくりで教養が積み上がる豆知識を1日1つ。クイズで定着させ、メモで振り返り、検索で再発見。
  • キーワードフィールド（100字）豆知識,雑学,日めくり,クイズ,毎日,教養,ウィジェット,勉強,知識,歴史,科学,トリビア

説明文の構造（推奨）

  1. 1行目（最重要）: 「毎日1つ、新しい豆知識を届けます」
  2. 2〜3行目: ホーム画面ウィジェット対応・スキマ時間で教養UP
  3. 機能リスト: 日めくり豆知識 / クイズ / ジャンル別問題集（17種） / クイズのヒント / お気に入り / カレンダー / Widget / ポイントで鳥の着せ替え
  4. 使い方: 起動するだけで今日の知識を表示
  5. 差別化ポイント: ポイントでジャンル解放・ヒント・鳥の着せ替え、Widget対応（着せ替えた鳥がウィジェットにも出る）、無料でも長く遊べる
  6. CTA: 「今すぐ無料でダウンロード」

説明文の変更点（1.0.14・未公開）

  • 今日のクイズを「4択」→「3択」に訂正（実装に合わせる）
  • 「14ジャンル1,400問」→「17ジャンル1,700問」。列挙に「日本の文化・行事、乗り物・交通、数学・論理」を追加。「他16ジャンルも最初の5問はお試し可能」＋「迷ったときは、ポイントを使うヒントで選択肢を減らせます」
  • 見出し「テーマカスタマイズ（13種類のテーマ）」を削除し「鳥の着せ替え」（帽子・マフラー・メガネなどの小物。着せた姿はホームとウィジェットにも登場）に置き換え
  • ポイントの使い道を「ジャンル解放・テーマ購入」→「ジャンル解放・鳥の着せ替え・クイズのヒント」
  • 年額の割引率を「45%お得」→「44%お得」に訂正
  • スクリーンショット: テーマショップの1枚（04_ThemeShop）を削除。まとめの1枚の副題からも「テーマ」を除いた

17ジャンルを ASO に活かす

本アプリは17ジャンル（歴史・科学・地理・文学/言語・芸術/音楽・スポーツ・食/料理・自然/動植物・宇宙/天文・テクノロジー/IT・医学/健康・心理学・雑学/トリビア・経済/お金・日本の文化/行事・乗り物/交通・数学/論理）を扱う（1.0.14 で後ろの3つを追加）。 各ジャンル名をキーワードフィールドに含めることで検索流入を広く獲得できる。

レビュー対策

  • ★4以上を維持する目標
  • レビュー依頼: 5回目起動と20回目起動のタイミング（ReviewService実装済み）
  • レビュー依頼前に2秒の遅延を入れて自然な流れに
  • 低評価には個別返信、要望は次バージョンに反映

マネタイズ最適化のヒント

  • 無料ユーザーに継続価値を提供（毎日のログインボーナス・お気に入り）
  • Premium特典: 広告なし・過去の豆知識の閲覧・月次ボーナス100pt（「限定テーマ」は存在しないため削除。1.0.14 でテーマ自体を廃止）
  • 動画ボーナス（最大5回/日 × 3pt = 15pt）でコイン経済を活性化
  • 有料16ジャンル × 100pt = 1,600pt ＋ 着せ替え全11点 1,650pt ＋ ヒント 10pt/回 → 自然な課金導線（1.0.14）
