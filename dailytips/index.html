DailyTips

日めくり豆知識アプリ（デイリー日めくり） · Bundle ID: com.happyboy1002.DailyTips

概要

  • カテゴリ教育 / リファレンス
  • 対応OSiOS 18.0+ / Swift 6.0
  • 言語日本語のみ
  • マネタイズサブスクリプション（月額/年額）+ Unity LevelPlay 3種広告（Banner / Interstitial / Rewarded）。アプリ起動広告（AppOpen）は 2026-08-20 に廃止。App Key・広告ユニットIDは設定済みだが ironSource Ads アカウント承認待ちのため現在は未配信
  • ステータスリリース済
  • リリース時期2026年4月
  • バージョン1.0.7 (build 19)
  • 表示名デイリー豆知識
  • Widget拡張あり（Small / Medium）
  • App Groupgroup.com.happyboy1002.DailyTips

アプリの目的

毎日1つの豆知識を表示する日めくりアプリ。豆知識ごとのクイズ、ジャンル別クイズショップ、テーマショップ、 Widget表示、コイン経済（ログインボーナス・動画報酬）を組み合わせて継続利用を促す設計。 v1.0.5 では学習メモ・検索・復習通知・無料体験枠などの新機能を追加し、教育アプリとしての価値を強化。

広告基盤の変更（2026-08-20 / 2026-08-23）

広告基盤を Unity LevelPlay へ移行した。 AdMob（2026-07-30 アカウント恒久停止）→ AppLovin MAX（publisher アカウントの承認が下りず断念）→ Unity LevelPlay（2026-08-20 移行完了）。

アプリ起動広告（App Open）は廃止。LevelPlay に該当フォーマットが存在しないため、AppOpenAdManager は API を残した無効スタブとしている。復活には App Open を持つ別ネットワークの併用が必要。

広告の配信は App Store 配信版のみ（AdEnvironment.isAdDeliveryAvailable = !appKey.isEmpty && isProduction）。 現在は ironSource Ads アカウントが承認待ちのため未配信。詳細は 広告制御 を参照。

LevelPlay への移行は 2026-08-20 に7アプリ、2026-08-23 に ITPassportMaster を実施し、全8アプリで統一されている。

2026-08-23 の要対応事項
  • ATT ダイアログの表示条件を shouldRequestTracking（= !appKey.isEmpty）へ分離する設計に変更した。現状のガード isAdDeliveryAvailable は isProduction を含むため、sandbox で走る App Store 審査ではダイアログが原理的に表示されない。同じ理由で 2026-08-22 に姉妹アプリ CHROMATIC 1.4.0(7) が Guideline 2.1 - Information Needed でリジェクトされた。DailyTips のコードは未適用
  • PrivacyInfo.xcprivacy は NSPrivacyTracking: false ＋ NSPrivacyTrackingDomains キーごと削除が正解（ITMS-91064 対策）。誤って戻さないこと

いずれも 広告制御 に詳細を記載。

  • 新ジャンル「経済・お金」100問追加（全14ジャンル1400問に）

v1.0.7 主な変更点（2026-05-25）

  • ジャンルクイズ「お試し5問」を1ジャンル1回限りに制限（再挑戦不可・お試し済みバッジ表示）
  • お試しモードで6問目以降が解けてしまう race condition を修正（GenrePlaySession 構造体でジャンル+モードをアトミック化）
  • テーマショップの価格表記を「枚」→「pt」に統一（ログインボーナス文言も含む4箇所）
  • アプリ起動広告：#if DEBUG return バイパス削除でシミュレータでもテスト広告で動作確認可能に
  • SKAdNetworkItems 71件追加（AdMob 公式推奨リスト）— Release/TestFlight での App Open Ad fill rate 改善

v1.0.5 主な変更点（2026-05-17）

  • 学習メモ機能（各日付に300字メモ・カレンダーに📝マーク）
  • 検索機能（タイトル・カテゴリ検索／お気に入り/既読/年度フィルター／検索結果から広告解放）
  • 復習通知（忘却曲線: 1日後・3日後・7日後の夜21:00）
  • 動画視聴ポイント獲得（1日5回・+3pt/回・全画面導線）
  • 無料体験枠（雑学・トリビアを完全無料化／他12ジャンルは最初の5問お試し）
  • 新ジャンル「心理学」100問追加（全13ジャンル1300問に）
  • 新テーマ「ベージュ」追加＋テーマ状態バッジ（使用中/購入済/無料/未購入）
  • 連続ログイン・連続正解バッジ表示／今日獲得pt表示
  • Widget に今日のクイズ問題を表示（解説はアプリで）
  • カレンダーに「今日」ジャンプボタン／2025/4/1 以前への遡及制限
  • SNS共有を画像カード付き（1080×1080）に刷新
  • アプリ起動広告の信頼性改善（SDK初期化待ち・4時間期限管理）
  • シート（モーダル）内からのリワード広告表示対応
  • App Group権限の正式設定（データ消失リスク解消）
