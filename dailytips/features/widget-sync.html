Widget同期機能

本体アプリと Widget 拡張のデータ同期メカニズム

v1.0 機能ID: DT-FEAT-WIDGET

概要

iOS の Widget 拡張は別プロセスで動作するため、本体アプリと直接データ共有できない。 AppGroup UserDefaults を経由してデータを共有する。本体起動時に最新データを書き込み、Widget が読み込む構造。

AppGroup 設定

enum WidgetAppGroup {
    static let suiteName = "group.com.happyboy1002.DailyTips"
    static let tipDataKey = "widgetTipData"
    static let calendarDataKey = "widgetCalendarData"
}

// UserDefaults へのアクセス（共通パターン）
let store = UserDefaults(suiteName: WidgetAppGroup.suiteName) ?? .standard

同期タイミング

イベント処理
本体アプリ起動時AppViewModel が syncWidgetData() を呼出
豆知識切り替え時（日付変更）HistoryService.markAsLogin() 経由で再同期
着せ替え時（1.0.14）小物を買う・着る・外す → syncWidgetData() → タイムライン更新（AppViewModel+Costume の didChangeCostume）
テーマ変更時（1.0.13）1.0.14 でテーマショップを廃止したため無し
WidgetCenter.shared.reloadAllTimelines()Widget の即時更新トリガー
Widget 自身の Timeline1時間ごと + 翌日0時に自動再取得

struct WidgetTipData: Codable, Sendable {

struct WidgetCalendarData: Codable, Sendable {
    let loginDaysThisWeek: [Bool]   // 7要素
    let loginStreak: Int
    let updatedAt: Date
}

配色（1.0.14）

1.0.14 でテーマを廃止し、ウィジェットもアプリと同じ配色「ひだまり」に固定した。WidgetTheme は本体の AppPalette（project.yml でウィジェットのターゲットにも含める）から色を引くだけで、共有領域のテーマ ID は読まない。

  • 背景 #FEF2E1 → #FEE7C7 → #FBD5A8 のグラデーション、文字は濃い色（#2E3440・補助 #545B69）。膜は重ねない
  • コントラストは単体テスト PaletteContrastTests で確認（旧 WidgetContrastTests の白文字＋黒い膜の確認は不要になった）
  • ※ 1.0.13（未公開）では選択中のテーマ ID（selected_theme_id）を読み、テーマの色＋明るいテーマは黒い膜、だった（DT-012）

着せ替えた鳥（1.0.14）

ウィジェットは App Group の costume_owned_ids・costume_equipped を CostumeOutfit.load() で読み、買っていない物・知らない id は捨てて描く。 定義（Models/Costume.swift）と素材（Costume.xcassets）は本体と共有。小は右下（幅64pt）、中は左（幅76pt）。CoinService はウィジェットに持たせない。

ビジネスルール

  • 本体・Widget の整合性は AppGroup UserDefaults を Single Source of Truth とする
  • Widget は本体に依存せず、AppGroup nil でも空表示で動作（リカバリは本体起動時）
  • 本体起動時に必ず syncWidgetData() を実行
  • 更新後は WidgetCenter.shared.reloadAllTimelines() で即時反映

実装メモ

  • project.yml で App Group capability 設定済み（本体・Widget両方）
  • TimelineProvider で policy: .after(startOfTomorrow)
  • HistoryService.syncWidgetData() で AppGroup 書込
  • 1.0.13: ウィジェット2種の紫固定のグラデーションをやめ、WidgetTheme で選択中のテーマの色を使う
  • 1.0.14: テーマを廃止し WidgetTheme は AppPalette（ひだまり）固定に。タイムラインのエントリに outfit（着ている小物）を追加
  • Widget の Smart Stack 対応（v1.x）
