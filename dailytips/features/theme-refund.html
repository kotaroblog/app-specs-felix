テーマ返金

テーマショップの廃止に伴い、ポイントで購入済みだったテーマの分をポイントで返す

v1.0 機能ID: DT-F-REFUND アプリ 1.0.14 (27)・未公開

概要

1.0.14 で配色を「ひだまり」1つに作り直し、テーマショップを廃止した。 これまでポイント（200pt）で有料テーマを購入していた人が損をしないよう、購入済みの有料テーマ1つにつき 200pt を残高へ戻す。 返金は1回だけで、返したことはホームの帯でお知らせする。テーマはアプリ内ポイントで売っていたもので、App Store の課金とは関係しない。

関連画面

  • ホーム（返金のお知らせの帯）
  • テーマショップ（1.0.14 で廃止）

処理フロー

sequenceDiagram participant App as アプリ起動 participant R as ThemeRefundService participant C as CoinService participant H as ホーム App->>R: refundIfNeeded() alt 返金済みの旗あり R-->>App: 0（何もしない） else 未返金 R->>R: 返金済みの旗を先に立てる R->>R: 購入済みの有料テーマ数 × 200pt opt 返金額 > 0 R->>R: お知らせ用の返金額を保存 R->>C: 残高へ加算 end end H->>R: pendingNotice() R-->>H: 返金額（あれば帯を表示） H->>R: 閉じる → dismissNotice()

ビジネスルール

  • 返金額 = 購入済みの有料テーマの数 × 200pt。最初から使えた無料テーマ3種（default・midnight・forest）は数えない。同じテーマが重複して記録されていても1つと数える
  • 返金は1回だけ。返金済みの旗を残高への加算より先に立てる（途中でアプリが落ちても、二重に返す側には倒れない）
  • 購入済みテーマの記録（unlocked_theme_ids）は消さずに残す（既存キーを変えない・後から戻せるように）
  • お知らせの帯は「テーマショップを終了しました。購入していたテーマの ◯pt をお返ししました。」。閉じるまで次の起動でも出す（表示前にアプリを終了しても見逃さない）。0pt の人には出さない

外部連携

連携先用途備考
App Group の UserDefaults購入済みテーマの読み出し・返金済みの旗・お知らせ用の返金額キーは データモデル を参照

エラー処理

発生条件対応
購入済みテーマが無い旗だけ立てて終わる。帯は出さない
旗を立てた直後にアプリが落ちたその回の返金は失われうるが、二重返金は起きない（安全側）

実装メモ

  • Services/ThemeRefundService.swift。テストは DailyTipsTests/ThemeRefundServiceTests.swift
  • 帯は Views/Home/ThemeRefundNoticeBanner.swift（閉じるボタンの読み上げ「返金のお知らせを閉じる」）
  • ログは os.log カテゴリ ThemeRefund（返金額を notice で1行）
