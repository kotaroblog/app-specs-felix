ジャンルクイズ機能

17ジャンル別の問題集とコイン経済の連携

v1.1 機能ID: DT-FEAT-GENRE

概要

17ジャンルから興味のあるものをコインで解放し、4つのプレイモード（ランダム/順番/続きから/お試し）で問題を解いていく機能。 進捗・履歴は AppGroup に保存。v1.1 で無料体験枠（雑学完全無料 + 全ジャンル5問お試し）を追加。

入口と入り方（1.0.13・未公開）

ジャンル別クイズに気づかれない・解放の直前で止まる問題（DT-015・DT-016）に対して、入口を増やし、入り方をジャンルの状態で分ける。

入口動作
ホーム上部の「クイズ」一覧（GenreQuizShopView）
ホームのポイントの使い道（「100ptで1ジャンル解放・あと◯pt」）一覧
今日のクイズの結果の下「「◯◯」のクイズをもっと解く」豆知識のカテゴリと同じジャンルへ（文化は無料の雑学・トリビアへ）。下表の判定で入り方を決める
お試し終了画面の「ほかのジャンルを見る」一覧
ジャンルの状態入り方
解放済み（無料ジャンルを含む）・回答あり続きから
解放済み・回答なし順番通り（1問目から）
未解放・お試し未使用お試し5問
未解放・お試し済み一覧を開いて解放を案内

判定（入り方・問題番号・関連ジャンル・ポイントの使い道）は画面に依存しない純粋な関数にして単体テスト（GenreGuidanceTests）で確認している。

無料体験枠（v1.1）

枠対象挙動
完全無料ジャンル雑学・トリビア（cost=0）全100問プレイ可能・進捗記録あり
お試し5問他16ジャンル（未解放時）GenrePlayMode.freeTrial で最初の5問のみ出題。進捗記録なし。終了時に「残り95問を解放しよう」誘導カード表示。v1.0.7: 1ジャンル1回限りに制限（完走後は「お試し済み」バッジで再挑戦不可）
// Models
enum GenrePlayMode: Equatable {
    case random, sequential, continued, freeTrial
}
enum GenreFreeAccess {
    static let freeTrialQuestionCount = 5
}

// v1.0.7: genre + mode をアトミックに渡してシート presentation 時の race condition を防止
struct GenrePlaySession: Identifiable, Equatable {
    let genre: GenreDefinition
    let mode: GenrePlayMode
    var id: String { "\(genre.id)-\(mode)" }
}

// GenreQuizService
func freeTrialQuestions(for genreId: String) -> [GenreQuizQuestion]
func isQuestionInFreeTrial(genreId: String, questionId: Int) -> Bool

// v1.0.7: お試し使用済みフラグ管理（GenreProgressService）
func isFreeTrialUsed(for genreId: String) -> Bool
func markFreeTrialUsed(for genreId: String)
// UserDefaults キー: "genre_free_trial_used_{id}"

API

@MainActor
final class GenreQuizService {
    func unlockGenre(id: String) -> Bool
    func isUnlocked(id: String) -> Bool
    func loadQuestions(genreId: String) -> [GenreQuizQuestion]
    func randomQuestion(genreId: String) -> GenreQuizQuestion?
}

final class GenreProgressService {  // @unchecked Sendable
    func getAnsweredCount(genreId: String) -> Int
    func getCorrectCount(genreId: String) -> Int
    func getPosition(genreId: String) -> Int
    func recordAnswer(genreId:, questionId:, correct:)
}

プレイモード

モード動作
ランダム毎回 randomQuestion() で異なる問題
順番通りposition をリセットして1問目から
続きから保存された position から再開

処理フロー（アンロック → プレイ）

  1. ユーザーがジャンルカードで「100コインで解放」タップ
  2. CoinService.spendCoins(100)
  3. GenreQuizService.unlockGenre(id:)
  4. AppGroup の unlocked_genres に追加
  5. 「プレイ」ボタン → モード選択
  6. Interstitial広告表示（無料ユーザー）
  7. GenreQuizPlayView で問題解答
  8. 各回答ごとに GenreProgressService.recordAnswer()

処理フロー（お試し終了 → その場で解放・1.0.13）

sequenceDiagram participant U as ユーザー participant P as GenreQuizPlayView participant S as GenreQuizService participant G as GenreProgressService U->>P: お試し5問を完走 P->>G: お試し使用済みを記録 P-->>U: お試し終了画面（解放ボタン or あと◯pt） U->>P: 「100ptで解放する」 P->>S: ジャンルを解放 S-->>P: 成功 P->>G: お試しの5問の回答をまとめて記録 P-->>U: 6問目から続ける

ビジネスルール

  • ジャンル解放は1ジャンル100コイン、買い切り（再購入不要）
  • プレイ開始時にInterstitial広告（無料）
  • 正解で streak +1、不正解で問題のみリセット
  • 履歴は最新から順に保存（AppGroup）
  • 1.0.13: ポイントが足りなくても解放ボタンは押せる。押すと「あと何pt」と貯め方（動画 +3pt〔1日5回〕・ログイン +1pt・今日のクイズの正解 +1〜3pt）を出す
  • 1.0.13: お試しの回答は解放したときだけ進捗に記録する（解放しなければ記録しない。従来どおり）
  • 1.0.13: 全問回答済みのジャンルは「最初から解き直す」で1問目から再挑戦できる
