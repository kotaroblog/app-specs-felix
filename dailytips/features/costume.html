鳥の着せ替え

ポイントで小物を買い、アイコンの鳥に着せる（ホーム・ウィジェットにも同じ姿で出る）

v1.0 機能ID: DT-F-COSTUME アプリ 1.0.14 (27)・未公開

概要

テーマショップの廃止でポイントの使い道が減ったため、1.0.14 で追加した。アプリアイコンから切り出した鳥に、頭・首・顔の小物を重ねる。 ポイントを貯める目的を「集める・着せる」楽しさにし、ホームとウィジェットで毎日目に入るようにする。

処理フロー

sequenceDiagram participant U as User participant V as 着せ替え画面 participant VM as AppViewModel participant S as CostumeService participant C as CoinService participant W as ウィジェット U->>V: 小物の「🪙 ◯pt」 V-->>U: 確認（鳥は試着の姿で表示） U->>V: 買う V->>VM: purchaseCostume VM->>S: purchase(id) S->>C: spendCoins(値段) alt 足りない S-->>V: あと◯pt（引かない） else 買えた S-->>VM: purchased VM->>S: equip(id)（自動で着せる・計測は送らない） VM->>W: ウィジェットのデータを同期・再描画 end

ビジネスルール

  • 買う: ポイントを引いて持ち物に足す。持っている物は二度と引かない。足りないときは引かずに「あと◯pt」を返す
  • 買ったらすぐ着せる。いつでも外せる
  • 着る: 買った物だけ。場所（頭・首・顔）ごとに1つ。同じ場所の別の物を着たら入れ替わる
  • 重ねる順は 鳥 → 首 → 顔 → 頭。素材はすべて鳥と同じ 860×730 の枠なので、重ねるだけで位置が合う
  • 読み上げは「豆知識の鳥（麦わら帽子・マフラー）」の形（並びは頭・首・顔）
  • 保存値から読むとき、知らない id・場所の食い違い・買っていない物は捨てる
  • 貯め方の案内: 動画を見て +3pt（1日5回まで）・毎日のログイン +1pt・今日のクイズの正解 +1〜3pt

外部連携

連携先用途備考

計測（AnalyticsService）costume_purchased（id・値段）・costume_equipped（id）買った直後の自動着用は「着た」に数えない

エラー処理

発生条件対応
残高不足アラート「あと◯ptで買えます」＋貯め方の案内。ポイントは引かない
保存値に文字列以外が混ざっている読める物だけ拾う（全体を捨てて、次の購入で持ち物を上書きで消さないため）
知らない id買えない・着られない（unknownItem）
